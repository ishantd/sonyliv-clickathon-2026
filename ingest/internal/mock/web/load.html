Set a viewer count, pick content, and watch traffic land. The generator is calibrated to the supplied extract — 40s heartbeat cadence, lognormal session durations, background and pause episodes, 7% late arrivals, 0.5% duplicates — so this exercises the same disorder the real stream has.

steady-state simultaneously active sessions — the natural dial here

share of sessions on one shared identity, reproducing the observed 95-concurrent outlier

content

pinning a handful is how you manufacture a live-event spike on one asset; sampling is the realistic spread

pace

speed 30 = 30 event-seconds per wall second; 0 = as fast as ClickHouse accepts
both 0 = run until stopped
measured rates: 7% out-of-order, 0.465% byte-identical duplicates. Set both to 0 for a perfectly ordered stream when isolating a bug from the disorder
server-side buffering; for small batches, not for 50k ones

ingest

sessions active per minute

This is the heartbeat-lease estimate, not served concurrency. It cannot retract paused or backgrounded time — on the supplied extract the same estimator peaks at 3,162 against an exact 2,305, so treat it as a liveness signal only. The exact curve needs the minute layer, which is not deployed yet.
